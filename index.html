Process

How a project runs, every time.

The same five stages, each with a written exit check, so you always know where the project stands and what comes next.

  1. Scope

    Discovery call, written scope, estimate, signed agreement.

  2. Design

    Architecture, data model, threat model and a plan you approve.

  3. Build

    Two-week sprints. CI/CD from day one. A demo after each sprint.

  4. Harden

    Acceptance testing, security scans, load tests, rollback rehearsal.

  5. Hand over

    Go-live, documentation, training and transfer of access.

Questions

Before you book a call.

Short answers to what clients usually ask first.

Who owns the code and infrastructure?

You do. Code lives in your own repository, infrastructure is defined as code, and cloud accounts, domains and credentials are rotated and transferred to you at handover.

How is pricing set?

Scoped projects are fixed price. MVP builds use milestone pricing. Ongoing work runs as a monthly retainer. You get a written scope and estimate before anything is signed.

How will we know how the project is going?

You see a working demo every two weeks, and each of the five stages ends with a written exit check.

What happens after go-live?

You receive documentation, runbooks and training for your team, plus a warranty period for defects. If you want ongoing help, we can continue on a retainer.

Do you work with teams outside Bangladesh?

Yes. BipTech is based in Dhaka and works with teams across time zones.
